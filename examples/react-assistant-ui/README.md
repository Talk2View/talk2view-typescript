# Talk2View — assistant-ui Example

Shows the "backend + frontend out of the box" path: the stock
[assistant-ui](https://www.assistant-ui.com) `<Thread />` — installed unmodified
from its shadcn registry, the same component any assistant-ui app renders —
driven entirely by `useTalk2ViewRuntime` from `@talk2view/sdk/assistant-ui`.
There is no Talk2View-specific UI in this example; the runtime hook is the
only Talk2View line in `src/App.tsx`.

## Setup

```bash
npm install
npm run dev
```

Open the printed URL. The composer, streaming replies, client tool calls and
tool-approval cards are all stock assistant-ui — Talk2View only supplies the
data behind them.

## Environment variables

- `VITE_T2V_PARTNER_KEY` — your partner key from the Talk2View dashboard.
  Defaults to `pk_test_example` if unset.
- `VITE_T2V_BASE_URL` — override the engine URL (e.g. for local development
  against `packages/server`). Omit it to use the SDK's default.

## What this demonstrates

- `useTalk2ViewRuntime({ partnerKey, tools })` creates a Talk2View client and
  exposes it as an assistant-ui `AssistantRuntime` — no `<T2VProvider>` or
  `/ui` components involved.
- `<AssistantRuntimeProvider runtime={runtime}><Thread /></AssistantRuntimeProvider>`
  is the entire integration surface.
- The same client tools as `examples/react-basic` (`show_notification`,
  `get_current_page`, `send_email`), including `send_email`'s
  `permission: true` — the agent pauses on it and assistant-ui's own approval
  card (rendered by the stock `ToolFallback` component) collects the
  end-user's decision.

## Re-theming the Thread

`src/components/assistant-ui/` and `src/components/ui/` were generated by the
assistant-ui shadcn registry (`npx shadcn@latest add @assistant-ui/thread`) —
they are not part of the SDK, and there is no adapter layer to work around.
They're yours: edit the Tailwind classes, swap components, or re-run the
registry command with `--overwrite` to pick up upstream changes. The
Talk2View runtime only supplies `AssistantRuntime`; it has no opinion on how
the thread looks.
